# Family Game Hub 🎮

가족과 함께 즐기는 게임 플랫폼

## 특징

- 🃏 **카드 뒤집기 게임**: 기억력 향상 게임
- 👨‍👩‍👧‍👦 **가족 프로필**: 각 가족 구성원별 기록 관리
- 📊 **통계 및 랭킹**: 주간 챔피언 시스템
- 🎨 **모바일 최적화**: 스마트폰에서 최적의 경험
- 🔊 **사운드 효과**: 재미있는 게임 피드백
- 💾 **로컬 저장**: 모든 데이터를 기기에 안전하게 저장

## 기술 스택

- React 18 + TypeScript
- Vite
- TailwindCSS
- Framer Motion
- Zustand
- React Router

## 시작하기

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
